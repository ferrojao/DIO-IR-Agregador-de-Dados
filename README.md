# 📊 Agregador de Dados para Declaração de Imposto de Renda

Projeto desenvolvido como parte de um desafio prático da **DIO**, com o objetivo de aplicar conhecimentos de Excel na construção de uma ferramenta para organização e consolidação de informações relevantes para a declaração de Imposto de Renda.

## 🎯 Objetivo

Criar uma ferramenta em Excel que facilite o processo de organização das informações necessárias para a declaração de Imposto de Renda, permitindo que o usuário registre seus dados de forma estruturada, organizada e validada.

A proposta é centralizar diferentes informações em uma única ferramenta, reduzindo a necessidade de consultar múltiplas fontes durante a preparação da declaração.

## 🧰 Funcionalidades

A ferramenta foi estruturada para oferecer:

* Organização centralizada das informações;
* Campos específicos para inserção dos dados;
* Validação de informações inseridas;
* Menus de navegação;
* Listas e opções de seleção;
* Padronização dos dados;
* Recursos para facilitar a utilização da ferramenta;
* Links rápidos para acesso a informações e funcionalidades relacionadas;
* Interface organizada para facilitar o preenchimento.

## 🗂️ Estrutura da Ferramenta

A planilha foi desenvolvida com foco em uma experiência simples e prática, permitindo que o usuário navegue entre as diferentes áreas da ferramenta e registre as informações necessárias de maneira organizada.

A utilização de menus, validações e campos estruturados contribui para reduzir erros de preenchimento e melhorar a consistência das informações armazenadas.

## ✅ Validação de Dados

Um dos recursos utilizados no projeto foi a **validação de dados**, permitindo controlar as informações inseridas pelo usuário e, quando aplicável, oferecer opções previamente definidas para seleção.

Esse recurso ajuda a:

* Evitar inconsistências;
* Padronizar informações;
* Reduzir erros de digitação;
* Facilitar o preenchimento;
* Melhorar a organização dos dados.

## 🔗 Links e Navegação

A ferramenta também utiliza recursos de navegação e links rápidos para facilitar o acesso às diferentes áreas da planilha e a informações relevantes.

Dessa forma, o usuário consegue utilizar a ferramenta de maneira mais intuitiva, sem precisar navegar manualmente por todas as abas.

## ⚠️ Observação

Este projeto possui finalidade **educacional e de organização de informações**.

A ferramenta não substitui a análise de um profissional contábil ou tributário e não constitui orientação fiscal ou tributária. As informações utilizadas para uma declaração de Imposto de Renda devem ser conferidas pelo próprio contribuinte e, quando necessário, por um profissional habilitado.
